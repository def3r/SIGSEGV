## : cmds
- `:q`
- `:w`
- `:bmark [name]` bookmark cur page
- `:bdelete [name]` delete bookmark
- `:exec [cmd]` run external cmd
- `:set [option]` settings
- `:info` doc info
- `:o`/`:open` open new doc

# Motions
- `R` refresh doc
- `r` rotate 90deg
- `C-r` invert fg and bg colors
- `Tab` sidebar
- `F5/F11` presentation mode
- `/` search forward
- `?` search backwards
- `f` show link hints
- `F` show link hints and load into Zathura
- `C` copy link URL to clipboard
- `m` creaete mark
- `\`` jumpt to mark
- `a`/`s` adjust fit/fill to screen
- `o`/`O` Open new doc
- `d` toggle dual page
- `C-n` toggle status bar
